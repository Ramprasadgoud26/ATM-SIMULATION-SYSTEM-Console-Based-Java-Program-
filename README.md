# 🏧 ATM Simulation in Java – Console Application

This project simulates the basic working of an **ATM system** using Java. Users log in with an **Account Number and PIN** and can perform essential banking operations in a secure console-based environment.

---

## ✨ Features

- **User Login**  
  Authenticate using Account Number + PIN.

- **Balance Inquiry**  
  Displays the current account balance.

- **Withdrawal**  
  Validates amount and prevents overdrawing.

- **Deposit**  
  Adds funds to the user account.

- **Exit**  
  Safe termination of the session.

---

## 🛠 Technologies & Concepts Used

- **Object-Oriented Programming (OOP)**  
  Implemented using classes, objects, and encapsulation.

- **Collections Framework (HashMap)**  
  Stores account details and PINs efficiently.

- **Exception Handling**  
  Manages invalid operations such as extra withdrawals or wrong input.
